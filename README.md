# Programación y analítica financiera con Python

**Financial Analytics Lab · Lenguajes de Programación · Ingeniería Financiera**

Este repositorio organiza de manera independiente **el aprendizaje**, **las evidencias evaluativas** y **la documentación académica**. Los materiales permiten estudiar los conceptos y practicar con Python; las entregas del proyecto se desarrollan individualmente y se registran en EduApp.

## Ruta académica

**Aprender → practicar → entregar → validar → interpretar.**

Los notebooks son materiales de estudio con ejercicios y comprobaciones formativas. Los **cuatro quices evaluativos** se realizan en EduApp. Las calificaciones, ponderaciones, fechas y autorizaciones se administran en la plataforma institucional; no se deducen automáticamente del repositorio.

### Proyecto integrador

El proyecto progresa mediante productos diferenciados: **análisis de portafolio en Colab**, **evaluación práctica individual**, **primera versión de la aplicación Streamlit** y **ampliación con sustentación**. La aplicación evoluciona sobre el mismo código, no exige construir dos aplicaciones independientes.

## Herramientas

Python · Google Colab · pandas · NumPy · yfinance · matplotlib · Streamlit · GitHub.

## Reproducibilidad y uso responsable

Cada análisis debe documentar fuentes, tickers, periodos, frecuencia, moneda, transformaciones, fórmulas y limitaciones. Los resultados históricos no garantizan rendimientos futuros ni constituyen asesoría de inversión.

## Compatibilidad con enlaces anteriores

Las carpetas originales `01_python_fundamentals/` a `06_financial_app/` y `nivelacion/` se conservan **temporalmente como rutas heredadas** para no interrumpir enlaces de Colab o referencias de EduApp. Para nuevas actividades utilizar las rutas `aprendizaje/` y `evaluaciones/`. Los archivos heredados no son la fuente recomendada para nuevas entregas.
