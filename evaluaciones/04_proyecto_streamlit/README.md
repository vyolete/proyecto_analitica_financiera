# Proyecto 2 y proyecto final · Aplicación Streamlit

**Una aplicación que evoluciona, no dos proyectos independientes.**

## Primera versión

Construir un analizador de un activo con selección de fechas, consulta de datos, indicadores, gráfico, validaciones y explicación de resultados.

## Ampliación final

Extender la misma aplicación para comparar varios activos, calcular rendimientos ponderados, correlaciones y medidas de riesgo, documentar supuestos y realizar la sustentación individual.

## Entregables

- Repositorio individual con archivos `.py`, dependencias e instrucciones de ejecución.
- Evidencia de funcionamiento, pruebas y limitaciones.
- Defensa individual de las decisiones de programación y análisis.

**Material de aprendizaje:** [Guía Streamlit](../../aprendizaje/06_streamlit/06_guia_streamlit.ipynb), [ejemplo inicial](../../aprendizaje/06_streamlit/app_ejemplo.py), [ejemplo ampliado](../../aprendizaje/06_streamlit/app_final_ejemplo.py).

Los ejemplos docentes son referencias para estudiar; no deben presentarse sin modificaciones como trabajo propio.

La distribución de notas entre primera versión, ampliación y defensa se conserva en EduApp y requiere aprobación docente.
