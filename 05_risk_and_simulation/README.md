# Risk & Simulation

Examinar correlación, covarianza, cuantiles, riesgo y simulaciones de escenarios; comunicar supuestos y limitaciones.

## Objetivo

Aplicar los conceptos mediante un caso financiero reproducible y documentado.

## Producto esperado

Análisis cuantitativo de escenarios de inversión.

## Estado

Estructura inicial. El material didáctico y el código se incorporarán progresivamente.
