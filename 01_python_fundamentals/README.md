# 01 · Fundamentos de programación

## El problema de análisis

Antes de estudiar la evolución histórica de los mercados, necesitamos comprender cómo representar una inversión mediante un algoritmo. Una posición financiera combina una cantidad de unidades con precios de compra y valoración; al relacionarlos, podemos calcular capital invertido, resultado monetario y rendimiento porcentual. Cuando se reúnen varias posiciones, surge un nuevo desafío: organizar la información y obtener indicadores coherentes para el portafolio completo.

## Qué se aprende

Este módulo desarrolla el pensamiento algorítmico a partir de un mismo caso financiero. Se estudian variables, tipos de datos y operadores para representar precios y cantidades; condicionales para identificar ganancias y pérdidas; listas y diccionarios para organizar posiciones; ciclos para procesar varios activos; y funciones para reutilizar y comprobar cálculos.

El propósito no es producir cifras aisladas, sino explicar qué representa cada indicador, cómo se obtiene y cuáles son los supuestos que limitan su interpretación.
