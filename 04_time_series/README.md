# 04 · Series temporales financieras

## El problema de análisis

El comportamiento de un activo no puede comprenderse completamente si se ignora el orden de las observaciones. Dos períodos con rendimientos promedio similares pueden presentar trayectorias diferentes, episodios de alta variabilidad o caídas pronunciadas desde máximos previos.

El análisis temporal permite examinar **cómo evolucionan los indicadores**, en qué momentos cambian y qué información adicional aporta la secuencia de los datos.

## Qué se aprende

Este módulo continúa el análisis exploratorio del portafolio. Se estudian los índices de fechas, las frecuencias de observación, los rezagos, los rendimientos acumulados y las ventanas móviles. Mediante pandas y matplotlib se calculan e interpretan medias móviles, volatilidad histórica móvil y drawdown.

El objetivo es comprender la definición de cada indicador, contrastar sus cálculos y reconocer los límites de las conclusiones obtenidas a partir de información histórica.
